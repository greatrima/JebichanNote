# 제비쨩 노트

**집배 현장에서 주소를 스캔하고, 집배구별 수취인 상태를 기록하는 Android 업무 보조 앱입니다.**

우편물의 주소와 이름을 읽어 등록된 수취인을 조회하고, 수취인 불명·이사감 등의 상태와 메모를 관리할 수 있습니다.

도로명변환기의 카메라·OCR·주소 인식 기능을 기반으로 분리한 **독립 앱**입니다. 도로명변환기와 함께 설치할 수 있으며, 설정과 저장 데이터는 서로 공유하지 않습니다.

## 시작하기

1. 앱을 실행하고 **설정 → 코드 입력**을 누릅니다.
2. `KPOST`를 입력합니다.
3. 인증이 완료되면 앱 내부 제목과 런처 이름이 **제비쨩 노트**로 바뀌고, 전용 아이콘이 적용됩니다.
4. **설정 → 집배구 설정**에서 담당 집배구를 추가하고 선택합니다.
5. **조회** 탭에서 우편물을 스캔합니다.

인증은 최초 한 번만 필요합니다. 앱 종료·재부팅·업데이트 후에도 유지되며, 앱 데이터 삭제 또는 삭제 후 재설치 시 초기화될 수 있습니다.

## 주요 기능

| 탭 | 기능 |
| --- | --- |
| **조회** | 카메라로 주소·이름 인식, 주소 후보 선택, 인식 결과 수정, 등록된 수취인 상태 확인 |
| **정보** | 수취인 등록·수정·삭제, 상태 선택, 메모 작성 |
| **목록** | 현재 집배구의 수취인 검색, 상태 필터, 정렬, 최근 조회 기록 |
| **설정** | 집배구 관리, 사전 갱신, 데이터 백업·복원, 화면 보호 설정 |

### 주소와 수취인 조회

- 기기 내 OCR로 주소와 한글·영문 이름 후보를 읽습니다.
- 주소 사전과 온라인 주소 API를 활용해 주소를 정리하고 검증합니다.
- 도로명주소·지번주소 인식과 양방향 변환을 지원합니다.
- 인식된 주소·상세주소·이름은 직접 수정할 수 있습니다.
- 동일 수취인은 이름만으로 판단하지 않고, 집배구·주소·동·호수·이름 등을 함께 비교합니다.

### 수취인 관리

수취인 상태는 **수취인 불명 / 이사감 / 기타** 중에서 선택합니다.

새 수취인은 인식 결과를 정보 탭에 불러와 등록하고, 기존 수취인은 저장된 상태와 메모를 확인하거나 수정할 수 있습니다. 삭제 전에는 확인창을 표시합니다.

목록에서는 이름·아파트명·도로명·주소·동·호수·메모를 한 검색창으로 검색할 수 있습니다. 최근 수정순·이름순·주소순 정렬과 최대 20건의 최근 조회 기록을 지원합니다.

### 집배구 관리와 인수인계

- 집배구를 추가·선택·이름 수정·삭제할 수 있습니다.
- 조회·검색·목록은 현재 선택한 집배구를 기준으로 동작합니다.
- 신규 수취인은 현재 집배구에 자동으로 저장됩니다.
- 집배구를 바꾸어도 기존 수취인의 소속은 변경되지 않습니다.
- 집배구 데이터를 내보내 Android 공유창으로 전달하고, 받은 파일을 가져올 수 있습니다.

중복 데이터는 **기존 정보 유지 / 받은 정보로 덮어쓰기 / 수정일이 최신인 정보 사용** 중에서 처리 방식을 선택합니다. 기본값은 최신 수정일 우선이며, 가져오기 전에 신규·중복·업데이트 건수를 확인할 수 있습니다.

## 백업과 개인정보

수취인 이름·주소·상태·메모는 기본적으로 **기기 내부에 저장**됩니다. 수취인 DB를 별도 서버에 업로드하는 기능은 없습니다.

- OCR은 기기 내에서 처리합니다.
- 주소 API에는 주소 검색에 필요한 기본주소만 전달하며, 수취인 이름·메모·상태는 보내지 않습니다.
- 인수인계와 전체 백업에는 암호화된 `.jebi` 파일을 사용합니다.
- 파일 암호는 앱에 저장하지 않습니다. 받는 분께 암호를 별도로 전달해주세요.
- 전체 복원은 병합 방식이며, 관련 없는 기존 데이터는 유지합니다.
- 최근 앱 화면의 내용 숨기기는 기본으로 켜져 있으며, 화면 캡처도 제한합니다.
- 자동 클라우드 백업 대신 앱의 전체 데이터 백업 기능을 이용합니다.

## 오프라인 사용

인터넷이 없어도 기기 내 OCR, 내장 주소 사전, 수취인 조회·등록·수정·검색을 사용할 수 있습니다.

새로운 지번↔도로명 변환과 온라인 주소 검증에는 인터넷이 필요합니다. 사전으로 정리된 주소는 실제 건물의 존재가 검증된 주소와 구분해 표시합니다. 주소 사전은 파일을 가져와 별도로 갱신할 수 있으며, 갱신에 실패하면 기존 사전을 유지합니다.

## 배포 및 개발

현재 이 저장소에는 앱 안내용 README만 등록되어 있습니다. **APK와 소스코드는 아직 등록되지 않았습니다.**

- 지원 환경: Android 6.0 이상
- 앱 설치 ID: `kr.co.jebichan.note`
- 도로명변환기와 별도로 개발·배포합니다.
- 도로명변환기를 참조한 패치는 별도 지시가 있을 때만 진행하며, 원본 저장소를 자동으로 동기화하지 않습니다.
- 전용 온라인 업데이트 배포 주소는 아직 설정되지 않았습니다.

OCR 결과는 사용 전에 확인해주세요. 특히 발신인과 수취인이 함께 보이는 우편물에서는 이름 후보를 직접 확인해야 합니다. 실제 기기의 카메라 동작·런처 아이콘 반영·외부 공유앱 전송은 추가 검증이 필요합니다. PIN·생체인증 잠금은 현재 버전에 포함되어 있지 않습니다.
